# Aram Events Templates

This starter project contains:
- Research notes for the 44 event categories visible in the supplied Zoho Backstage screenshot.
- A list of 15 website themes observed in the supplied screenshots/document.
- Five original, responsive Business event registration page examples.

## Run
Open any `templates/business/*.html` file in a browser, or use VS Code Live Server.

## Important
The registration forms are front-end demonstrations only. They show a confirmation message but do not save registrations. A backend or registration service is needed for real submissions.

## Next
Use these five designs as the approved design pattern set, then adapt the visual concepts to the remaining categories. The 44 categories × 5 designs target would be 220 pages.
